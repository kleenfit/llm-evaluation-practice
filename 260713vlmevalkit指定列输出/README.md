# VLMEvalKit Evaluation Excel Export

## Overview

This module extends the default VLMEvalKit evaluation pipeline by exporting inference and evaluation results into a readable Excel file.

Compared with the original output files, the exported Excel is intended for manual inspection, result analysis and downstream processing.

The component consists of:

- `run.py` (integration and command line options)
- `vlmeval/utils/eval_excel.py` (Excel export implementation)

---

# Installation

Replace the following files in your VLMEvalKit project:

```
VLMEvalKit/
├── run.py
└── vlmeval/
    └── utils/
        └── eval_excel.py
```

No additional dependencies are required beyond those already used by VLMEvalKit.

---

# Workflow

The export module is integrated into the normal evaluation pipeline.

```
Inference
        │
        ▼
Prediction File
        │
        ├─────────── mode=infer
        │                 │
        │                 ▼
        │          Export Detail Sheet
        │
        └─────────── mode=all / eval
                          │
                          ▼
                  dataset.evaluate()
                          │
                          ▼
                  Export Detail + Summary
```

The original VLMEvalKit workflow is preserved.

---

# Features

- Export Excel automatically after inference or evaluation.
- Support both inference-only and evaluation workflows.
- Export original questions and model predictions.
- Export evaluation summary after `dataset.evaluate()`.
- Support user-defined export fields.
- Automatically remove temporary intermediate files.
- Preserve all available columns by default (no hardcoded dataset schema).

---

# Output

## `--mode infer`

Only model inference is performed.

The exported Excel contains:

```
Detail
```

Typical exported fields include:

- index
- question
- hint
- A
- B
- C
- D
- answer
- prediction

No evaluation-related fields are generated.

---

## `--mode all`

Inference and evaluation are both performed.

The exported Excel contains:

```
Detail
Summary
```

### Detail

Contains one row per sample.

Typical fields include:

- index
- question
- answer
- prediction
- hit
- log

Additional columns generated by the dataset are also preserved automatically.

### Summary

Contains the metrics returned by

```
dataset.evaluate(...)
```

---

# Export Directory

Specify the export directory with

```bash
--eval-excel-dir <directory>
```

Example:

```bash
--eval-excel-dir ./outputs/export
```

The generated file name follows the format:

```
<Model>_<Dataset>_eval.xlsx
```

---

# Custom Export Fields

The exported columns can be customized using JSON.

Example:

```bash
--eval-fields '["index","question","A","B","answer","prediction"]'
```

Only existing columns will be exported.

If this option is omitted, every available column from the generated result file will be exported.

# Examples

## Inference Only

```bash
python run.py \
    --model qwen3.5-35b-a3b \
    --base-url https://qianfan.baidubce.com/v2 \
    --key "$QIANFAN_KEY" \
    --data MMBench_V11_MINI \
    --mode infer \
    --api-nproc 1 \
    --eval-fields '["index","question","A","B","answer","prediction"]' \
    --eval-excel-dir ./outputs/infer_export \
    --work-dir ./outputs/infer_export
```

Generated Excel:

```
Detail
```

---

## Full Evaluation

```bash
python run.py \

    --api-nproc 1 \
    --eval-excel-dir ./outputs/eval_export \
    --work-dir ./outputs/eval_export
```

Generated Excel:

```
Detail
Summary
```

---

# Notes

- This module does not modify the original VLMEvalKit evaluation logic.
- The export process is executed automatically after inference or evaluation.
- Temporary files are created inside the corresponding output directory and removed automatically after successful export.
- Exported columns are determined dynamically from the generated result file.
- No dataset-specific field list is hardcoded.
- Existing output files with the same name will be overwritten.

# File Structure

```
VLMEvalKit
├── run.py
└── vlmeval
    └── utils

```

`run.py` integrates the export functionality into the evaluation pipeline.

`eval_excel.py` is responsible for locating the generated result files, selecting export fields and writing the final Excel workbook.
